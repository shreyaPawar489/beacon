# Beacon

**Try it: https://beacon-eight-tau.vercel.app** (best on a phone)

Anonymous safety reporting for UC Berkeley. File a report through a short guided chat; when someone else reports the same person, you're matched, see a shared case file, and can choose to go to Title IX together.

Demo match is on by default: if nobody else has reported the same person yet, a clearly labelled sample report shows you how a match works.

Run locally: `npm install && npm run dev`, or `npm run booth` to serve to phones on the same Wi-Fi.
